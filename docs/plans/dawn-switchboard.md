# 세 번째 게임: 새벽의 배전반

## 목표

- 3–6명이 서로 다른 회로 단서를 말로 조합하는 부분정보 협력 퍼즐이다.
- 개인 승자 없이 세 개의 배전반을 모두 복구하면 공동 승리한다.
- 12분과 퓨즈 3개를 세 단계 전체에서 공유한다.

## 게임 흐름

1. 각 플레이어가 개인 화면에서 단서를 읽고 준비한다.
2. 연결된 플레이어가 모두 준비하면 12분 카운트다운이 시작된다.
3. 활성 플레이어가 다음 칸에 들어갈 모듈 하나를 확정한다.
4. 정답이면 모듈이 잠기고, 오답이면 퓨즈 하나를 잃는다. 두 경우 모두 턴은 다음 연결된 플레이어에게 넘어간다.
5. 4칸, 5칸, 6칸 배전반을 차례로 해결한다.
6. 퓨즈가 0이 되거나 시간이 끝나면 공동 패배하고, 세 번째 배전반을 완성하면 공동 승리한다.

같은 칸에서 이미 실패한 모듈은 다시 선택할 수 없다. 화면은 서로 보여주지 않되 단서 문구는 그대로 읽거나 자유롭게 설명할 수 있다.

## 퍼즐과 등급

- 쉬움·보통·어려움 각 6개, 총 18개의 고정 퍼즐을 사용한다.
- 모든 퍼즐은 구조화된 제약 조건으로 표현하며 가능한 순열을 전수 검사해 유일한 정답을 보장한다.
- 한 판에서는 난도별 하나씩 선택하고 재경기에서는 직전 퍼즐 세 개를 제외한다.
- 승리 시 남은 시간과 퓨즈로 공동 복구 등급을 계산한다.
  - 3성: 퓨즈 3개, 4분 이상
  - 2성: 퓨즈 2개 이상, 2분 이상
  - 1성: 그 밖의 승리

## 상태와 정보 공개

```text
BRIEFING
  -> SOLVING
  -> PANEL_RESULT
       -> SOLVING
       -> GAME_OVER
```

플레이어 행동은 `MARK_READY`와 `CONFIRM_MODULE` 두 가지다. 전체 정답과 단서 배분은 서버 스냅샷에만 둔다. 공개 투영에는 현재 후보, 잠긴 순서, 실패 후보와 연결이 끊긴 플레이어의 비상 단서만 포함한다. 개인 투영에는 본인의 단서와 현재 허용된 행동만 추가한다.

활성 플레이어가 45초 이상 연결되지 않으면 다음 연결 좌석으로 턴을 넘긴다. 해당 플레이어의 현재 단계 단서는 공개 보드의 비상 매뉴얼로 옮겨 퍼즐이 막히지 않게 한다. 재접속자는 이후 턴부터 다시 참여한다.
