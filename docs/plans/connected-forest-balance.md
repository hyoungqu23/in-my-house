### 선택의 의미와 숲길의 비중

## 목표

보상과 방문 대상 선택 규칙을 함께 비교한다. 특정 인원수·발신 방식에서만 맞는 후보를 확정하지 않는다. 기존 prototype-1과 고정 Python golden 결과는 보존한다.

## 사전 판정 기준

1. CORE 전략(STAY/WALK/MIXED)은 4·5·6인 각각, 짧은 길·무작위·완성 임박 발신 모델 각각에서 승률 격차 10%p 미만을 목표로 한다. 인원수 평균으로 실패를 숨기지 않는다.
2. 홀드아웃 시드에서 반복 확인하고, 게임 단위 bootstrap으로 승률 격차의 불확실성을 계산한다. 같은 게임 내 참가자 결과를 독립 표본으로 취급하지 않는다.
3. 합법 두 선택의 비율은 전체 방문의 70% 이상을 목표로 한다. 조건을 강제로 제한해 승률만 맞추는 후보를 경계한다. 발신자가 두 이웃 중 자유롭게 고를 수 있는 비율도 기록한다.
4. 상황 판단 봇은 새로운 방문객, 자신의 남은 서식지 자리, 숲길 진행, 공개 점수를 사용한다. 타인의 손·활성 동물·미래 덱을 보지 않는다. 자유 선택에서 두 행동이 모두 실제로 등장하는지 확인한다.
5. 황금 도토리·교환권 사용, 배치 판단 실수, 응답 큐 순서, 여러 발신 행동이 섞인 테이블에 대한 민감도를 확인한다.
6. 방문 횟수와 수신 보상 차이를 함께 기록해 방문 몰아주기 피드백으로 생긴 승률 편향을 찾는다. 숲 꾸미기와 동물 맞이의 점수 가치가 사라지는 후보는 채택하지 않는다.

35–65% 자유 산책 선호와 숲길 점수 비중은 원래 설계의 진단 목표다. 봇의 한 휴리스틱에서 정확히 절반을 만들기 위해 숫자를 조작하지 않는다. 고정 전략만이 아니라 판단 전략의 결과와 합법 선택 여부를 함께 해석한다.

## 실험 축

- 머물기 기본 하트, 산책 기본 잎, 완성 보너스 수신자·발신자 몫을 동시에 변경한다.
- 새로운 종류의 방문객을 처음 맞이하면 추가 하트를 받는 `visitorDiversityHearts`를 비교한다. 반복 방문객에는 중복 보너스가 없다.
- FREE: 현재와 같이 좌우 이웃을 자유롭게 고른다.
- ALTERNATE: 이전에 덜 방문한 자기 이웃을 우선한다. 방문 횟수가 같으면 둘 중 선택한다.
- BALANCED_INCOMING: 이전 계절까지 받은 방문이 적은 이웃을 우선한다. 현재 계절의 미공개 선택은 사용하지 않는다.

실험용 규칙 필드는 production 기본값에 적용하지 않았다. 등록된 prototype-1에서 생략하면 기존 보상과 자유 발신을 유지한다.

## 설계와 재현

- `src/modules/connected-forest/analysis/balance-experiments.ts`: 후보, 독립 좌석 배정, 인원수별 원시 결과, 군집 bootstrap.
- `scripts/connected-forest-balance.ts`: 단계별 실험과 JSON 체크포인트. 후보 하나가 끝날 때마다 파일을 갱신한다.
- CORE: 머물기 고정, 산책 고정, 초반 산책·후반 머물기를 기본으로 하는 기존 혼합 전략.
- SMART: 머물기 고정, 산책 고정, 즉시 보상·자리 비용·다음 방문·공개 상대 점수를 보는 판단 전략.
- DIVERSE: 고정 둘, 판단 전략, 무작위 수신 전략을 섞은 추가 스트레스 테이블.
- 발신 모델은 세 기존 모델에 공개 점수가 낮은 이웃을 고르는 D 모델과 서로 다른 모델이 섞인 테이블을 추가한다.
- 덱, 발신, 배치 실수, 응답 순서, 수신 무작위 선택은 서로 다른 난수 스트림을 사용한다.
- 공동 승리는 실제 승리 확률과 승리 기여도 분할 값을 모두 기록한다.
- 응답 순서를 바꿀 때도 수신자 내부의 방문 큐 순서는 보존한다.

## 단계

1. 작은 표본으로 넓은 후보를 탐색한다. 탐색 단계 결과는 확정 근거가 아니다.
2. 유망 후보를 더 큰 표본과 판단 전략으로 비교한다.
3. 독립 시드·도구 사용·배치 실수·응답 순서를 포함한 홀드아웃으로 검증한다.
4. 선택된 후보의 결과를 실제 reducer 경로와 대조하고, 현재 플레이용 기본 규칙 변경 여부를 결정한다.

원시 JSON은 `docs/plans/assets/forest-balance-*.json`에 저장한다. 최종 선택과 근거는 실험 완료 후 추가한다.

## 현재까지 확인한 결과

- 78개 후보를 4·5·6인, 세 발신 모델, 60판씩 비교했다. 평균이 아니라 각 조건의 최악 격차로 좁혔다.
- 여섯 후보를 새 시드 900000의 300판과 CORE/SMART 전략으로 다시 비교했다.
- 번갈아 방문 / 머물기 1 + 새 방문객 종류 1 / 산책 2 / 완성 양쪽 1 / 길 상한 3 후보는 시드 314159의 1,000판에서 모든 30조건의 최악 승률 격차 6.2%p, bootstrap 95% 상한 9.5%p였다.
- 시드 271828의 1,500판에서는 최악 7.1%p, 불확실성 상한 10.3%p였다. 평균만으로 확정하지 않았다.
- 도구 사용과 응답 순서를 섞은 시드 161803에서는 승률 격차가 4.9%p였지만 자유 선택률 최소 65.6%였다. 점수 균형만으로 채택하지 않고 선택 가능성 개선을 실험한다.
- 길 상한을 4로 늘린 세 후보를 시드 173205에서 도구·응답 순서·즉시 판단 전략까지 포함해 300판씩 비교했다. 자유 선택률 최소 약 72.3%, 숲길 점수 몫 약 25–29%였다. 탐색 결과라 아직 확정 근거로 삼지 않는다.
- 낮은 좌석 번호로 고정하는 동점 발신 처리와 계절의 원형 방향을 따르는 처리를 추가 비교한다. 전략별 승률뿐 아니라 자리별 승률도 기록한다.
- 시뮬레이터는 실제 서버와 같이 현재 큐의 불가능한 방문을 즉시 배웅한다. 행동 기록을 실제 reducer에 재입력해 도구·후보 규칙·모든 인원수·세 응답 순서의 최종 선수 상태, 숲길, 방문 이력, 점수와 승자가 일치하는지 테스트한다.

`forest-balance-progress-summary.json`에는 현재 단계별 집계가 있다. 조건별 결과 파일과 engine SHA-256을 함께 읽어야 한다. 중간에 검증 정확도를 높인 엔진 변경이 있으므로 서로 다른 엔진 해시의 행을 하나의 확정 표본처럼 합치지 않는다.
