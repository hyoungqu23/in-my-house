# 두 번째 게임: 수상한 초대장

## 목표

- 3–6명이 휴대폰의 비밀 정보와 공용 보드를 오가며 즐기는 단어 추리·블러핑 게임이다.
- 정해진 라운드 수나 역할 순환 없이, 참가자들이 원할 때까지 이어서 플레이한다.
- 매 라운드가 끝난 뒤 전원이 다음 라운드 진행 여부를 투표하고, 종료가 결정되면 누적 점수가 가장 높은 플레이어가 승리한다.

## 한 라운드의 흐름

1. 서버가 카테고리와 비밀 단어를 고르고 Stranger 한 명을 무작위로 정한다. 같은 플레이어가 연속 또는 여러 번 Stranger가 될 수 있다.
2. Guest는 카테고리와 비밀 단어를, Stranger는 카테고리만 개인 화면에서 확인한다.
3. 모든 플레이어가 비밀 단어를 직접 말하지 않는 짧은 단서를 휴대폰으로 제출한다.
4. 공용 보드가 단서를 동시에 공개한다. 45초 동안 대화한 뒤 각자 Stranger라고 생각하는 플레이어에게 비밀 투표한다.
5. 최다 득표자가 단독 1위면 지목된다. 동률이면 아무도 잡히지 않은 것으로 처리한다.
6. 지목된 플레이어가 Stranger라면 네 개의 후보 중 비밀 단어를 추측한다. 지목이 빗나가거나 추측이 맞으면 Stranger가 라운드에서 이긴다.
7. 라운드 결과와 누적 점수를 공개한 뒤 `계속하기` 또는 `종료하기`를 투표한다.

3인 게임에서는 단서가 너무 적지 않도록 서로 다른 질문으로 단서를 두 번 제출한다. 4–6인 게임에서는 한 번 제출한다.

## 점수와 종료

- Stranger가 지목을 피하거나 비밀 단어를 맞히면 Stranger가 2점을 얻는다.
- Stranger를 정확히 지목하고 단어 추측도 막으면 Stranger에게 투표한 Guest가 각각 1점을 얻는다.
- 라운드 종료 투표에서 `종료하기`가 전체 플레이어의 과반이면 즉시 게임을 끝낸다. 과반이 아니면 새 라운드를 시작한다.
- 종료 투표에 제한 시간은 두지 않는다. 연결이 끊긴 플레이어를 어떻게 처리할지는 게임 구현 단계에서 재접속 정책과 함께 확정한다.
- 게임 종료 시 누적 점수가 가장 높은 플레이어가 승리하며, 동점 승리를 허용한다.
- 재경기는 점수와 사용한 단어 기록을 초기화한 새 게임으로 시작한다.

## 상태 머신

```text
ROUND_INTRO
  -> CLUE_SUBMISSION
  -> CLUE_REVEAL
  -> DISCUSSION
  -> VOTING
  -> STRANGER_GUESS? 
  -> ROUND_RESULT
  -> END_VOTE
       -> ROUND_INTRO
       -> GAME_OVER
```

핵심 플레이어 행동은 다음과 같다.

- `SUBMIT_CLUE`
- `CAST_SUSPICION_VOTE`
- `GUESS_WORD`
- `CAST_END_VOTE`

## 정보 공개 원칙

- 전체 상태, 비밀 단어, Stranger 좌석, 공개 전 단서와 개별 투표는 서버에만 둔다.
- Guest 개인 화면에는 현재 비밀 단어를 제공하고 Stranger 개인 화면에는 제공하지 않는다.
- 단서는 제출 단계가 끝난 뒤에만 공개하며, 의심 투표는 해당 단계가 끝난 뒤 집계 결과만 공개한다.
- 종료 투표는 누가 무엇을 골랐는지 숨기고 제출 인원만 표시한다. 결과가 확정되면 계속 또는 종료만 공개한다.

## 구현 순서

1. 게임 카탈로그와 방의 `gameId`를 추가한다.
2. `suspicious-invite`의 순수 TypeScript 상태, 전이, 점수 계산 테스트를 작성한다.
3. 공개/개인 투영을 판별 유니온으로 확장하고 비밀 정보 누출 테스트를 작성한다.
4. 방 모듈이 게임별 생성·전이·투영 구현을 선택하도록 실제 두 번째 adapter를 연결한다.
5. 휴대폰 개인 화면과 공용 보드를 구현한다.
6. Playwright 다중 컨텍스트로 3인·6인 게임, 종료 투표, 동점, 재경기를 검증한다.

## 구현 결과

- 카탈로그가 게임 식별자, 노출 상태, 최소·최대 인원을 소유한다.
- 방 생성 요청과 영속 스냅샷에 `gameId`를 넣는다.
- `dark-house`와 `suspicious-invite`를 모두 플레이 가능한 게임으로 노출한다.
- 두 게임의 reducer와 projection을 game runtime의 판별 유니온 seam에 연결한다.
- 종료 투표는 모든 좌석의 제출을 기다리며, 연결이 끊긴 플레이어는 같은 기기로 재접속해 투표를 마쳐야 한다.
