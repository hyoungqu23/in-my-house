## Edge Cases

- 호출자가 제출 후 원본 `welcome`을 바꿔도 잠긴 상태와 최종 주민 위치가 바뀌지 않는다.
- 호환 칸도 산책 가능 숲길도 없는 방문은 큐 진입 즉시 배웅하며 20초 대기가 없다.
- 공개 연출은 연결 해제로 멈추지 않으며, 다음 draft에서 끊긴 좌석의 입력이 필요해지면 멈춘다. 방문 큐가 끝난 수신자의 연결 해제도 다른 큐를 막지 않는다.
- 30판·1000판, 4·5·6인 각각에서 모든 좌석의 정책별 배정 횟수 차이가 최대 1이고 모든 판에 세 정책이 존재한다.
- seed 70027의 34점 동률에서 방문객이 많은 1번만 승자로 집계하며, 후보 보상 설정도 공통 승자 판정에 반영한다.
- 잘못된 인원수·rulesVersion·setup, 손에 없는 카드, 비인접 배치, 이미 찬 피규어 칸, 잘못된 habitat 회전.

- 마지막 계절 동물 보충 생략, 황금 도토리 1회 제한, 교환과 같은 카드 welcome 충돌, 덱 draw 불변식 위반.
- 여러 방문 큐의 서로 다른 deadline, 서버 시간이 여러 deadline을 지난 상태, 반복 `advanceTimedState` 호출.
